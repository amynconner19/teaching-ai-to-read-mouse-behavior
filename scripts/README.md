# BIOMAP Analysis Scripts

This directory contains the current Python scripts used to calculate BIOMAP behavioral metrics from DeepLabCut tracking data.

## Current Script

- `BIOMAP_SoundAssay_Analysis6.1.py`

This script is the current laboratory workflow used after DeepLabCut analysis. It calculates facial and body-position measurements, normalizes measurements to baseline, and exports summary CSV files.

The BrainHack goal is **not** to rewrite the scientific methods, but rather to automate this workflow and integrate it into a reproducible end-to-end pipeline.
