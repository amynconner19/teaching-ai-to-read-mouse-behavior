# Example Videos

This folder provides example behavioral videos for developing and testing the automated BIOMAP pipeline.

## Download

📥 [Download the example behavioral video from Google Drive](https://drive.google.com/file/d/1f8y_uXNYOb40_Jp7LwBjLqWS94HDiFoX/view?usp=drive_link)

## Intended Use

Use this video as the input for the automated pipeline. The pipeline should:

1. Run the trained DeepLabCut models.
2. Generate tracking CSV files.
3. Run the trained SimBA model. 
4. Generate standardized figures and analysis-ready outputs.

> The video is hosted externally because it exceeds GitHub’s file-size limit.
